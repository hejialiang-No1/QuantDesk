## QuantDesk v1.0.1 —— 美股量化终端

macOS 桌面端美股量化终端，国内网络直连可用，无需 API Key。

### 本次新增

- **推荐买入 / 卖出区间**：买区由前期支撑、均线、布林中轨、ATR 回调带取交集密度最高的一段；卖区分三档（40% / 35% / 25% 减仓），并给出止损位、盈亏比与建议仓位
- **全面诊股**：六维打分（趋势 / 动量 / 量能 / 位置估值 / 波动 / 流动性）+ 机会清单 + 风险清单（带等级）+ 8 项体检 + 结论文本，每条结论都带可核对的数值依据
- **个股期权策略**：Black-Scholes 定价 + 期权链（含 Δ / IV）+ ±1σ 期望波动区间 + 10 种策略的收益结构与适配度排序
- **K 线控制修复**：修掉缩放 / 平移时可见区间出现小数下标导致绘制崩溃的问题；右边缘锁定、双击复位、Shift+滚轮横向平移、滚轮以光标为锚点、工具条缩放 / 复位 / 回到最新
- **界面重做**：按 macOS 26/27 Liquid Glass 规范重构，玻璃材质、同心圆角、侧栏延伸到边缘、滚动边缘效果，深色 / 浅色 / 跟随系统三态

### 其余模块

- **自选行情**：实时报价、红涨绿跌、市盈率 / 市净率 / 换手率、自动刷新、内置股票池
- **个股分析**：K 线 + MA/BOLL 主图，成交量 / MACD / KDJ 副图
- **量化选股**：6 因子打分，支持导出 CSV
- **策略回测**：双均线 / MACD / RSI / 布林带 / 动量 / 海龟 + 买入持有基准，含手续费与滑点、防未来函数
- **预警监控**：价格上破 / 下破 / 涨跌幅超阈，命中触发系统通知

### 数据源

东方财富 → 腾讯 → 新浪 三源自动降级。估值字段已按市场做优先级解析（美股 f163/f164，A股 f9/f115），无数据统一显示 `--` 而非 `0.00`。

### 安装

1. 下载下方 `QuantDesk-1.0.1-arm64.dmg`
2. 双击挂载，把 QuantDesk 拖入 Applications
3. 若被 Gatekeeper 拦截：

```bash
sudo xattr -dr com.apple.quarantine /Applications/QuantDesk.app
```

或在 Finder 中右键 → 打开。

### 已知限制

- 仅 macOS arm64（Apple Silicon）
- 未做 Apple 开发者签名，首次打开需右键打开或 xattr 解锁
- 行情延迟约 15 分钟，用于研究而非实时交易
- 期权为 Black-Scholes 理论价，未考虑买卖价差与提前行权

### 风险提示

本工具用于量化研究与回测演练，所有信号、评分、区间、期权策略与回测结果**不构成投资建议**。
