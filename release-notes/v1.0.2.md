# QuantDesk v1.0.2 Release Notes

**发布时间**：2026-09-13
**升级建议**：推荐所有 v1.0.x 用户升级。

## 一句话总结

把 QuantDesk 从「行情 + 分析 + 选股 + 回测」扩展为完整的「数据 → 研究 → 回测 → 模拟 → 风控 → 监控 → 税务」个人美股量化闭环。

## 主要新增

| 模块 | 文件 | 能力 |
|---|---|---|
| 美股规则引擎 | `src/shared/market.js` | 交易时段、假期、T+1、PDT、SSR、LULD、熔断、真实费用、做空 |
| 绩效归因 | `src/shared/perf.js` | CAGR / 夏普 / 索提诺 / 卡玛 / 最大回撤 / VaR / Beta / Alpha / 归因 |
| 税务复盘 | `src/shared/tax.js` | FIFO 配对、Wash Sale、短期/长期资本利得、报税表、CSV 导出 |
| 风控中心 | `src/shared/risk.js` | 账户/策略/做空三层风控、安全评分、下单前预检 |
| 模拟交易 | `src/shared/paper.js` | 状态机撮合、部分成交、T+1 结算、对账、上线就绪度 |
| 券商适配 | `src/shared/broker.js` | IBKR / Alpaca / Tradier / TradeStation / Schwab / E*TRADE，仅导出不代下单 |
| 选股器增强 | `src/shared/screener.js` | 六类股票池、六因子、参数扫描、策略对比 |
| 监控告警 | `src/shared/alerts.js` + `src/main/notify.js` | 16 规则 / 10 异常 / 6 渠道，含 SMTP 双 TLS 路径 |
| 新界面 | `src/renderer/index.html` + `app.js` + `app.css` | 模拟交易、风控、监控告警、税务复盘四个视图 |

## 关键修复

- 券商对账单用 `side` 字段时税务报告产出空结果（最危险的静默失败模式）
- 多策略对比返回的 `rows` 未排序导致「最优策略」与表格首行不一致
- 模拟盘只认 `price`/`limitPrice` 不认 `quote`，市价单被拒
- 模拟盘幂等键含实时报价，可绕过重复提交
- IBKR 订单未校验 `conid`
- PDT 日期归一不统一导致误判剩余额度
- SMTP AUTH 顺序错误（看起来像密码错）
- SMTP STARTTLS 死循环
