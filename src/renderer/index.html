关于

QuantDesk 本地运行的美股量化终端。行情来自公开接口，指标、因子评分、诊股、期权定价与回测全部在本地计算，不上传任何数据。
  • 数据源：东方财富 → 腾讯 → 新浪，三源自动降级，国内直连
  • 技术指标：MA / EMA / MACD / RSI / BOLL / KDJ / ATR / OBV，全部本地实现
  • 诊股：六维打分 + 机会风险清单，每条结论都带可核对的数值依据
  • 期权：Black-Scholes 理论定价 + 对数正态分布积分求胜率，支持手动覆盖 IV
  • 回测：信号次日开盘成交，含手续费与滑点，对比买入持有基准
风险提示：本工具仅用于量化研究与教学演示，所有信号、评分、区间与策略均不构成投资建议。期权为高杠杆衍生品，可能损失全部本金。
