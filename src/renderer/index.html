关于

QuantDesk 本地运行的美股量化终端。行情来自公开接口，指标、因子评分、诊股、期权定价与回测全部在本地计算，不上传任何数据。
  • 数据源：东方财富 → 腾讯 → 新浪，三源自动降级，国内直连
  • 技术指标：MA / EMA / MACD / RSI / BOLL / KDJ / ATR / OBV，全部本地实现
  • 诊股：六维打分 + 机会风险清单，每条结论都带可核对的数值依据
  • 期权：Black-Scholes 理论定价 + 对数正态分布积分求胜率，支持手动覆盖 IV
  • 美股规则：交易时段与半日市、EST/EDT 夏令时、T+1 结算、PDT、SSR、LULD 价格带、三级熔断
  • 回测：真实费用分项（SEC / FINRA TAF / 交易所 / 清算 / CAT）、五种订单类型、止损止盈与移动止损
  • 模拟交易：部分成交、滑点、T+1 结算队列、券商快照对账、上线就绪度清单
  • 风控：账户级 / 策略级 / 做空专项三层约束，下单前预检返回拦截与警告
  • 绩效：卡玛 / 索提诺 / 信息比率 / VaR / 归因 / 换手率成本拖累，基准可选 SPY / QQQ / IWM
  • 监控：主进程轮询 + 10 类异常检测 + 6 个推送渠道（Telegram / 企业微信 / 钉钉 / Webhook / 邮件 / 系统通知）
  • 税务：FIFO 回合配对、洗售检测、长短期分档、1099-B / 1099-DIV / 1042-S 归类、境外所得抵免估算
风险提示：本工具仅用于量化研究与教学演示，所有信号、评分、区间与策略均不构成投资建议。期权为高杠杆衍生品，可能损失全部本金。
